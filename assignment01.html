QISKIT · ASSIGNMENT 01

Qubit & Superposition

Qiskit을 이용하여 Qubit과 중첩(Superposition)의 기본 원리를 실습합니다.

01

Objective

이번 과제에서는 양자컴퓨팅의 기본 단위인 Qubit을 이해하고, Hadamard Gate를 이용하여 중첩 상태를 구현하는 것을 목표로 합니다.

Classical Bit가 0 또는 1 중 하나의 값을 가지는 것과 달리, Qubit은 측정하기 전까지 여러 상태의 중첩으로 표현될 수 있습니다.

02

Theory

하나의 Qubit 상태는 일반적으로 다음과 같이 표현할 수 있습니다.

|ψ⟩ = α|0⟩ + β|1⟩

α와 β는 각 상태의 probability amplitude이며, 측정 확률의 합은 1이 되어야 합니다.

|α|² + |β|² = 1

초기 상태 |0⟩에 Hadamard Gate를 적용하면 |0⟩과 |1⟩이 동일한 측정 확률을 가지는 중첩 상태가 됩니다.

H|0⟩ = (|0⟩ + |1⟩) / √2

03

Qiskit Code

하나의 Qubit으로 Quantum Circuit을 만들고 첫 번째 Qubit에 Hadamard Gate를 적용합니다. 

from qiskit import QuantumCircuit

qc = QuantumCircuit(1)

qc.h(0)

qc.draw("mpl")

04

Result

Hadamard Gate를 적용한 Qubit을 측정하면 이상적인 경우 |0⟩과 |1⟩이 각각 약 50%의 확률로 관측됩니다.

STATE |0⟩

≈ 50%

STATE |1⟩

≈ 50%

05

What I Learned

이번 실습을 통해 Classical Bit와 Qubit의 차이와, Hadamard Gate가 중첩 상태를 만드는 데 사용된다는 점을 이해했습니다.

또한 Quantum State의 probability amplitude와 실제 측정 확률이 서로 다른 개념이라는 점을 확인할 수 있었습니다.

06

Qubit Playground

아래 Quantum Gate를 직접 적용하여 하나의 Qubit 상태가 어떻게 변하는지 확인할 수 있습니다.
