QISKIT · ASSIGNMENT 01

Qubit & Superposition

Qiskit을 이용하여 Qubit과 중첩(Superposition)의 기본 원리를 실습합니다.

01

Objective

이번 과제에서는 양자컴퓨팅의 기본 단위인 Qubit을 이해하고, Hadamard Gate를 이용하여 중첩 상태를 구현하는 것을 목표로 합니다.

02

Theory

하나의 Qubit 상태는 일반적으로 다음과 같이 표현할 수 있습니다.

|ψ⟩ = α|0⟩ + β|1⟩

초기 상태 |0⟩에 Hadamard Gate를 적용하면 |0⟩과 |1⟩이 동일한 확률을 가지는 중첩 상태를 만들 수 있습니다.

H|0⟩ = (|0⟩ + |1⟩) / √2

03

Qiskit Code 

from qiskit import QuantumCircuit

qc = QuantumCircuit(1)

qc.h(0)

qc.draw("mpl")

04

Result

Hadamard Gate를 적용한 Qubit은 측정 시 |0⟩과 |1⟩이 각각 약 50%의 확률로 관측됩니다.

STATE |0⟩

≈ 50%

STATE |1⟩

≈ 50%

05

What I Learned

이번 실습을 통해 Classical Bit와 Qubit의 차이와, Hadamard Gate가 중첩 상태를 만드는 데 사용된다는 점을 이해했습니다.
